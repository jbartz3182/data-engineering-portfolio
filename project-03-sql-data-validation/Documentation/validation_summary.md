# SQL Data Validation Summary
<br>

## Overview
<br>

This project demonstrates the use of SQL to identify and investigate common data quality issues within a relational database.
<br>

## Validation Checks Performed
<br>

### 1. Missing Email Addresses
- Identified customer records with NULL email values.
- Result: 1 record found.
<br>

### 2. Duplicate Customer Names
- Identified customer names appearing more than once.
- Result: John Smith appeared 2 times.
<br>

### 3. Negative Product Prices
- Identified products with prices below zero.
- Result: 1 record found.
<br>

### 4. Negative Quantities
- Identified order items with negative quantities.
- Result: 1 record found.
<br>

### 5. Orphaned Orders
- Identified orders referencing customers that do not exist.
- Result: 1 record found.
