# SQL Data Validation Project
<br>

## Overview
<br>

This project demonstrates the use of SQL to identify, investigate, and document common data quality issues within a relational database.
<br>

## Objectives
<br>

- Identify duplicate records.
- Identify missing values.
- Detect invalid data.
- Find orphaned records.
- Validate referential integrity.
- Improve overall data quality.
<br>

## Dataset Information
<br>

- Source: Sample relational database
- Tool Used: SQL Server
- Dataset Type: Customer, Product, and Order Data
<br>

## Validation Checks Performed
<br>

### 1. Duplicate Records
- Identify duplicate customer and transaction records.
<br>

### 2. Missing Values
- Locate records containing NULL or blank values.
<br>

### 3. Invalid Data
- Identify negative quantities, invalid prices, and other data quality issues.
<br>

### 4. Orphaned Records
- Identify child records that do not have matching parent records.
<br>

### 5. Referential Integrity
- Validate relationships between tables using primary and foreign keys.
<br>
