Power Query Data Cleaning Project

Overview:
This project demonstrates the use of Microsoft Power Query to clean, transform, and prepare data for analysis and reporting.

Objectives:
Import raw data,
Identify data quality issues,
Standardize values and formatting,
Transform data into an analysis-ready format,
Create calculated columns,
and Document transformation steps.

Skills Demonstrated:
Power Query,
Data Transformation,
Data Cleaning,
Data Preparation,
Data Quality Management,
and Documentation.
