# Power Query Data Cleaning Project
<br>

## Overview
<br>

This project demonstrates the use of Microsoft Power Query to clean, transform, and prepare raw data for analysis and reporting.
<br>

## Objectives
<br>

- Import raw data from external sources.
- Identify data quality issues.
- Standardize values and formatting.
- Transform data into an analysis-ready format.
- Create calculated fields.
- Document transformation steps.
<br>

## Dataset Information
<br>

- Source: To Be Determined
- Tool Used: Microsoft Power Query
- Dataset Type: Business Data
<br>

## Cleaning Actions Performed
<br>

### 1. Duplicate Records
- Identify and remove duplicate records.
<br>

### 2. Missing Values
- Review and document missing data.
- Apply appropriate data-cleaning techniques.
<br>

### 3. Data Standardization
- Standardize text values, dates, and formatting.
<br>

### 4. Column Transformations
- Split columns where necessary.
- Merge columns where appropriate.
- Create calculated columns.
- Rename fields for readability.
<br>

### 5. Data Validation
- Validate transformed data against business rules.
